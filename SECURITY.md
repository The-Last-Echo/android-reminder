# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through GitHub’s **Report a vulnerability** feature in this repository’s Security tab, if it is enabled. If private reporting is unavailable, open a public issue asking the maintainers for a private contact; do not include exploit details or sensitive data in that issue.

Please do not publicly disclose a vulnerability before it has been investigated and, where appropriate, fixed.

Include the affected app version, Android version and device, a concise description of the impact, steps to reproduce, and relevant logs or proof of concept. Remove personal data and secrets from any attachment.

The maintainers will try to acknowledge reports and follow up as reasonably possible. This project has no formal response-time guarantee. Security fixes are intended for the latest released version; older releases may not receive backports.
